# ReadMe

# Reading Aloud and Artificial Intelligence

## A Preventive Approach for Dyslexia Detection

This repository contains the final implementation and materials developed for the project:

**"Lectura en veu alta i intel·ligència artificial: Un enfocament preventiu per a la detecció de la dislèxia"**
(*Reading Aloud and Artificial Intelligence: A Preventive Approach for Dyslexia Detection*)

The objective of this work is to explore different machine learning and artificial intelligence approaches for the early detection of dyslexia through the analysis of oral reading recordings and derived speech features.

---

# Repository Structure

The repository includes two complementary versions of the project:

### 1. Modular Python Project

The complete implementation has been organized into folders and Python files to provide a cleaner, more maintainable, and production-oriented structure.

This version is intended for development, experimentation, and reproducibility purposes.

### 2. TFG.ipynb

Alongside the modular project, the repository also includes the notebook:

**TFG.ipynb**

This notebook contains the entire project in a single file and corresponds to the original development environment used during the research process in Google Colab.

It provides a complete and self-contained view of all experiments, preprocessing steps, feature extraction pipelines, model training procedures, and evaluations conducted throughout the project.

# Main Execution Files

The project includes two main entry points:

## main_without_paths.py

This script is intended to execute the complete pipeline from scratch.

It performs all required stages, including:

* Dataset loading
* Audio preprocessing
* Feature extraction
* Dataset generation
* Model training
* Evaluation

This option should be used when reproducing the project from the beginning or when rebuilding all intermediate artifacts.

---

## main_with_paths.py

This is the version used during the final stages of development and experimentation.

Instead of recomputing every intermediate step, it loads previously generated datasets, processed variables, and stored results.

This significantly reduces execution time and allows rapid testing and evaluation of the different approaches implemented in the project.

# Implemented Approaches

The project explores several machine learning approaches for dyslexia detection.

Each approach follows a different strategy for feature extraction, representation, and classification, allowing comparison between methodologies and performance.

The implementation of every approach can be found in its corresponding module within the project structure.

---

## Approach 1

This approach focuses on the extraction of handcrafted features from the audio recordings and the subsequent training of traditional machine learning classifiers.

The objective is to establish a baseline and evaluate the predictive power of manually engineered speech-related features.

---

## Approach 2A

This approach leverages pretrained speech representations (embeddings) extracted directly from the audio recordings.

Instead of relying solely on handcrafted descriptors, the models learn from richer latent representations generated by state-of-the-art speech processing architectures, allowing the capture of more complex acoustic and linguistic patterns associated with dyslexia.

---

## Approach 2B

Approach 2B relies on a significantly more computationally intensive training process.

Due to the large training time required (several hours), the trained variables and model artifacts were serialized and stored as `.pkl` files.

This decision was made to:

* Avoid repeatedly retraining the models.
* Facilitate faster experimentation and evaluation.
* Improve reproducibility of the reported results.

For this reason, the repository does not necessarily include all trained artifacts by default.

If access to the trained `.pkl` files is required, please contact the author using the email provided in the contact section below.

## Approach 3

The third approach combines the strengths of the previous methodologies through an Early Fusion strategy.

In this setup, the handcrafted acoustic features extracted in Approach 1 are concatenated with the speech embeddings obtained in Approach 2 before the classification stage.

The goal is to exploit complementary information sources:

Handcrafted features provide interpretable speech and reading-related descriptors.
Learned embeddings capture high-level acoustic patterns that may not be explicitly represented by manual features.

# Summary

This project investigates the potential of artificial intelligence techniques for the preventive detection of dyslexia through oral reading analysis.

Multiple approaches were designed, implemented, and evaluated, ranging from traditional machine learning pipelines to more advanced representations requiring extensive training procedures.

To facilitate both reproducibility and ease of use, the repository provides:

* A modular Python implementation.
* The original Google Colab notebook (`TFG.ipynb`).
* Precomputed datasets and stored intermediate artifacts used during experimentation.
